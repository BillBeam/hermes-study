## 2. 主要学习成果(成品章 `chapters/r7b-platform-integration.md`)

1. **接入面的价值在于"规定各平台可以在哪些维度上不一样"**,而非"统一了什么"。
   能力位默认全取最保守值,且每个都有"说谎也不挂"的第二道降级(返回 False
   **或**抛异常都回落)。
2. **结构性发现:枚举数 ≠ 内建适配器数**。24 个 `Platform` 枚举,但
   `_create_adapter` 只剩 **9 个内建分支**且**插件注册表先查**;其余是 22 个插件 +
   1 个能一对多的 relay。三条接入血统的成本曲线截然不同(内建改 16 处 / 插件改 0 处 /
   relay 连网关侧代码都不写)。
3. **第一层守卫**(R7 移交项落点):三字典状态机,一个 `asyncio.Event` 兼"忙标志"与
   "中断信号"两职,由此产生"清空 Event 但保留键"的中间态 —— 回合链正确性的支点。
   **第一层默认不打断**,真正的策略机在第二层(证据见 §4 ▲1)。
4. **两个把进程搞挂的 issue 都出在释放路径**:#17758(递归排水按链长增长 C 栈,
   ~2000 帧后 SIGSEGV,无 traceback)→ 改 `create_task` 交棒 + 属主转移;
   #48300(两个**各自正确**的保守策略组合成不可恢复态)→ 释放-**有条件**删属主。
   后者是全簇最精妙的一处,也是单元测试测不出的一类 bug。
5. **api_server:无状态协议接有状态 agent**。哈希"系统提示 + 首句"造确定性会话 ID,
   零客户端改造;两个**正交**的会话头(`X-Hermes-Session-Id` = 哪段转写、
   `X-Hermes-Session-Key` = 谁的记忆),分别堵**读**别人历史与**写进**别人记忆域。
   #10760 的修法是范式级的:**把必须永远取某值的参数从签名里删掉**,让错误状态不可表达。
6. **fd 是网关第一稀缺资源**,本簇两次事故同源不同因:#38803(配置错误被误分类为
   可重试 → 无限重连,每圈泄漏一个 SQLite 连接,2.5 天 1002 fd,EMFILE 拖垮整个网关)、
   #18451(7 个长驻适配器的 httpx 默认 keepalive 在透明代理后累加撞 256 fd 上限)。
7. **媒体投递是一条被反复加固的外泄边界**:符号链接早于一切检查解析;允许根无条件
   优先于拒绝名单(运营方意图 > 内置策略);默认宽/严格窄两档且取舍写进注释;
   新鲜度启发式被自动续期的 OAuth token 打破过,修法是配一份"永不适用"清单;
   凭据清单读/写/外发**三面共用一份**。
8. **relay 把能力位从"方法"变成"数据"**(`CapabilityDescriptor`,frozen)。配套:
   多平台按 key 存表 + 显式标量默认(否则退化成最后写入者胜);信任边界上做**取值**
   归一化(`max_message_length=0` 是合法 JSON 但会静默截空所有回复);
   `delivered_via_upstream_relay` **本地盖章、永不读线**;一条出站单向 WS 同时解决
   NAT 穿透与延迟敏感的边缘 ACK。

## 5. 测试作为行为规格(notes/r7b-95)

**四批 117 文件 / 1,102 用例通过,0 行为失败。**
唯一一次失败 `test_webhook_adapter.py::TestDualStackBind` 经实测确证为**环境限制**:
本容器无 IPv6 协议族(`bind('::')` → `EAFNOSUPPORT`,`/proc/net/if_inet6` 不存在),
而被测代码 `DEFAULT_HOST = None` 的语义正是"按解析出的每个地址族各建套接字",
只解析出 IPv4 时只建 IPv4 是**正确行为**;同文件其余 33 例全通过。

本簇 issue 命名测试 5 个(#11016 / #25107 / #73771 / #75349 / #31501)全部纳入并通过。
**未跑全量 `tests/`**(R7 已做过 Top-42 大盘),故未跑部分不在本轮结论断言范围内。
